# Adversarial and underwriting evaluation extension

Codex (AI), November5 2026. Eleven new reproducible offline tests, not a production decision service or evidence of predictive creditworthiness. These tests include successful reproductions of unsafe assumptions; a green test suite does not mean those weaknesses are fixed in deployment. Run `python -m unittest -v test_stress` and `python stress.py` from this directory. The latter reproduces stress-results.json without network or random sampling.

## Highest-priority acceptance tests still missing

1. **Durable execution and settlement:** production adapter plus canonical deployed path, with independent receipt verification, expiry/nonce/recipient/amount binding, crash/retry/reorg/parallel-worker cases, issuance stop and continued repayment/withdrawal access. Owner: Codex implementation after transition; existing application owner retains release responsibility until transferred.
2. **Evidence compromise:** forged documents, compromised trusted endorsers, stale or revoked verification, malicious content and scripts across actual rendering/extraction/storage boundaries. The current deterministic guard tests only its narrow pinned source boundary. Trusted relationships must never confer execution authority.
3. **Portfolio/model validity:** unknown controller/group membership, intersecting groups, adverse selection, changing attack prevalence, affordability shocks, liquidity and appeals. Independent temporal holdout and prospective real-outcome evidence are prerequisites to any calibrated predictive claim; no cohort or dataset is currently available. Do not select threshold values using these illustrative scenarios alone.
4. **Observed release and permitted chain route:** source compatibility is verified through appf834f4e, but deployed version/wiring/policy enforcement remain unverified. Current canonical RPC is still outside the selected environment's enforced policy. Existing owner must provide an independently authorized execution/configuration route; no combined inventory/ACP dispatch or denied-route bypass.
5. **Human readiness:** accepted facilitator/custodian, private consent/withdrawal/access/retention proof and actual permitted invitation channel. Fixed fictional read-only PhaseA can evaluate comprehension/accessibility; PhaseB also requires release/isolation/resource/receipt evidence. Neither establishes real repayment behavior.
