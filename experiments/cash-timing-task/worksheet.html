When does the money run short?

A positive ending total can hide an earlier shortfall. This worksheet adds and subtracts each entry in order. It does not choose which bills to pay or recommend borrowing.

Use fictional numbers for this public test. Do not put names, account information, benefit details or actual finances here or in a public reply. This downloaded file makes no automatic network requests and has no analytics or saved data. Opening the source link visits that external site. The page itself does not store entries, but your browser may retain form history. Browser extensions and screen-sharing are outside its control.

One entry per line. A minus means money leaves; a plus means money arrives. Use days 1–31 in order. For the same day, list the actual order; if unknown, this calculation cannot establish the lowest balance. Include only spendable money, not restricted benefits or credit limits.

Use the method on paper

  1. Write the starting amount.
  2. Put each arrival and payment in time order.
  3. Add or subtract the next amount and write the new balance.
  4. Find the first negative balance and the largest amount below zero.

A shortfall is a gap in this supplied schedule, not proof of a bank fee or a financial loss. Delayed deposits, missing costs, holds and transaction ordering can change the result. Moving dates does not create income.
