## Method and limits

- **Their words** are read from the cooperative's public source repository, `Techne-Co-op/techne.coop`, at commit `7b4e34f` (2026-09-17), which was still the head when I fetched at 10:41 UTC on 2026-10-07. The glosses are copied by script from `commons/build/lexicon/lexicon.json` (76 terms), so they are verbatim; their file says "The prose page governs; this artifact distills", and a gloss is "the first sentence of the page definition". `AGENTS.md`, `CONTRIBUTORS.md` and the Authority Map are quoted where named. The live site and regenhub.xyz are not reachable from my environment.
- **Our words** are quoted from this project's source: `scottonchain/microcredit-contract` at `4dc09f7` and this repository at `a1dbf64`.
- A script rebuilt every quotation from those files and failed if one was missing. I read published text only: I make no claim about how their organizers use a term in practice, and "collision" means two published meanings, not an error on either side.

## One example in both vocabularies (illustrative: no such exchange has happened)

Their Lexicon marks every event "real or illustrative"; this one is illustrative.

| Step | In our words | In their nearest words |
| --- | --- | --- |
| The maintainer posts card #21 | a task card with a pinned command, an expected output and a time cap | a piece: "The unit of work: one complete thing a pair of hands can make in a session, carrying an address, an intent, citations, a readiness condition, a deliverable, an acceptance, and its honest status." |
| An outside agent takes it | a claim, with a scope reply within about four hours | a Run serving a Direction: "A Run is one isolated working session serving one Direction." |
| It returns a report | one Markdown file, or a comment, with the command, the commit and the actual output | the deliverable of the piece, with the check it ran and the commit it ran against (their `CHECK` rule) |
| A second reader checks it | the Codex lane checks before the maintainer accepts | an acceptance demonstrated: "A piece's acceptance was demonstrated and an organizer marked it so, with evidence cited." |
| One correction | a correction cycle, the old text kept | "How a wrong event is handled, since it cannot be erased: a new event is written that compensates for the old one and points back at it." |
| Credit | credit by handle in the fixture README | the provenance pair or trailer: "The two hands on everything a Run makes: Authored-by names the instrument, Directed-by names the member who directed it." |
