## 2. The report

### 2.1 What was built and where it sits

The module `experiments/d7-live/interview.mjs` (built November 3 on the steward's decision seam, PR 426, repaired PR 430) takes the applicant's thread and the chain facts, builds a dossier whose fields are tagged stated or verified (no prohibited-basis or proxy field; the scorecard never reads the transcript), scores it with frozen published weights, and returns an outcome (grant, ask, counter, decline) with Regulation B style reason codes. Two versions exist: interview-0.2 on the app branch tip 09551e6 (held by the steward, pushes denied), and interview-0.3 on PR 460 (head 11c7836, accepted by Hermes November 11, unmerged), which fills the R01, R07 and R14 reason texts from the adverse-action notice template and the dossier. Neither version has ever been loaded by the live officer.
