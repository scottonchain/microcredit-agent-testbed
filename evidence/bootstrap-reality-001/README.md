# Grounded bootstrap: paid-input agents, funded jobs, and conserved trust paths

Codex (AI), 2026-10-07. Research plus an executed reference simulation. No mainnet deployment, paid API purchase, actual customer sale, independently controlled commercial borrower or new EVM transaction is claimed. This packet distinguishes (a) primary-source mechanisms/current catalog observations, (b) actually produced and accepted useful work, and (c) modeled finance around a paid-input analogue. All three are necessary to interpret the result.

## What research changed

The first practical borrower should perform an already-funded service requiring upstream cash, not trade speculatively or borrow merely to build reputation. The agent-world analogue of working-capital microcredit is **buying paid API/tool inputs before a customer releases payment for accepted work**. A funded job narrows customer nonpayment; it does not eliminate rejection, late release, disputes or task failure. If the buyer can release input money earlier, use prepayment instead of inventing a loan need.

Six lending/network protocols and ten agent-finance/payment implementations were examined through pinned primary code/docs, supplemented by Hermes's current official-web/catalog reads. See protocols/FINDINGS.md, protocols/protocol-comparison.json, agents/RESEARCH.md and commerce/FINDINGS.md. Snapshots contain commit IDs, exact files and hashes; their existence is not proof of deployment/adoption/performance.

## Bootstrap demonstrated in the reference model

Simulation seed:5USDC lender liquidity and1USDC separately staked by a sponsor; three test buyers fund0.50USDC escrow each. **All are modeled cash, not balances we moved.** The lender knowingly supplies mission/mechanics seed; these grace-period loans earn no interest and demonstrate no commercial lender yield. Sponsor explicitly consents to bounded onward delegation via the coordinator; this broad risk consent is not claimed to be an endpoint-specific signature.

Two workers each start with0USDC. Officer grants remain0 throughout. Each obtains0.20USDC along `stake sponsor → coordinator → worker`, against one shared finite stake lot. The model spends0.10 for ten search calls at the sourced catalog price and an **assumed**0.05 inference budget;0.05 remains unused/retry capacity. The actual work still runs from free pinned cached data; these are paid-API analog expenses, not real purchases.

After source-output acceptance, modeled0.50 customer escrow pays0.20 directly toward the loan, releases0.30 to the worker, and the worker pays a modeled0.01 sponsor success fee. Worker ends with0.34USDC before an **assumed**0.005USD native-gas cost. Graph commitments clear; the same stake supports the other new worker. The first worker's repeat job now pays0.15 inputs from retained cash and takes **no loan**; it ends0.69 before its two gas allowances. Second worker ends0.34. Lender withdraws all5; sponsor releases its1 plus0.02 modeled fees. Every recorded modeled transfer conserves the initial7.5USDC. Customer capital funds earnings; no circular principal repayment creates credit.

This demonstrates **issuer-free two-hop access, settlement and self-financing progression in a runnable reference simulation**. It does not demonstrate today's contract has transitivity or that a real customer will pay0.50. Output acceptance is genuinely executed, but the bids/revenues/inference/native-gas/fees and escrow adapter are explicit fixtures. All role agents share this experiment's controller. A seed operator/relayer must supply native gas;0workerUSDC does not mean infrastructure is free.

Adverse branch: delivery rejected, buyer's modeled escrow refunded, sponsor declines rescue,0.15 input spend consumed. At syntheticday61, the0.20 secured allocation is slashed; lender recovers5 principal, sponsor stake falls to0.80, worker's unused0.05 remains separately reclaimable. No forced cure or fabricated customer income. This is resource-accounting default in a reference model; actual current-contract clock/write-off receipts are still a separate Hermes task.

Admission also rejects unfunded buyer escrow, bids below the conservative0.215 worst-case input/retry+fee+gas screen, changed quotes exceeding the0.20 loan cap, missing consent, insufficient pool liquidity and exhausted shared backing. Graph attacks cover simultaneous borrowers, diamonds, cycles, locked exits, exact partial repayment, default stake depletion, duplicate completion and sub-cent principal remaining locked. In-process locks serialize competing admission. The allocator discovers paths algorithmically (depth<=4edges,<=1,000 queue visits/queued candidates,<=16 allocation paths), then reserves all roots/edges together. Its deterministic greedy allocation proves feasible capacity only, not maximum throughput, fair ranking or default-probability calibration. Python locking is not durable EVM transaction atomicity; graph+escrow+cash still needs an onchain implementation/proof.

## What is and is not economical

No simple first-loan route beats direct funding automatically. A sponsor willing to advance0.20 directly can use less capital; a buyer who prepays inputs removes the gap entirely. The pool needs a measured service advantage—shared liquidity across independent providers, standard settlement/risk limits or reduced coordination—not merely a larger number of loans. Ten API searches are not mandatory if free inputs meet the buyer's requirements. The actual cached report correctly gets NO_LOAN.

At the selected tariff, baseline input0.10+inference0.05+sponsor0.01+gas0.005 gives0.165 break-even before unpriced labor/hosting/other fees; with the full0.20 advance spent, the conservative floor becomes0.215. A0.50 modeled bid leaves0.335 after the stated gas allowance in the successful job; a0.20 bid is declined under the worst-case policy. These are scenario results, not an observed market margin. If API price doubles or inference rises enough,0.20 may be insufficient; re-quote and decline or resize with actual buyer/backer consent. The bidder must cover valued labor, platform/facilitator fees, failed-call/rejection probabilities and capital lock before a sustainable-business claim.
